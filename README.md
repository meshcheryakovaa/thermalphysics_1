# thermalphysics_1

## О чём статья

Прогрев золя не лимитирует осаждение кремнезёма в фотополимерном микроканале: тепловая релаксация занимает секунды, подвод реагента к стенке — минуты, гелеобразование — часы. Поэтому задача сводится к квазиизотермической, а температура входит в решение только через профиль стенки $T_w(z)$. Распределение слоя по длине задают отношение скорости поверхностной реакции к скорости подвода реагента и осевая неоднородность $T_w$.

Из этого выводятся три критерия в замкнутой форме:

1. **Осевая равномерность в проточном режиме** — ограничение на эффективное число Дамкёлера $\mathrm{Da}_{\text{эф}}$ и минимальный расход $Q_{\min}$.
2. **Допустимая неоднородность температуры стенки** $\Delta T^*$ — центральный теплофизический результат (специальность 1.3.14).
3. **Предельная масса осадка в статическом режиме** $m_{\max}$ и статическое число Дамкёлера $\mathrm{Da}_{\text{ст}}$.

Прикладная цель — модель низкопроницаемого керна с пережимами микрометрового масштаба, поэтому к критериям добавлены закон сужения канала, условие его устойчивости и оценки достижимой проницаемости.

Статья даёт публикационную опору положениям 1–3 диссертации (главы 2 и 3). Режимная карта с двумя маршрутами формирования слоя (положение 4) остаётся для второй статьи.

## Постановка

| Параметр | Значение |
| --- | --- |
| Радиус канала $R$ | 250–500 мкм |
| Длина $L$ | 20–30 мм |
| Температура стенки $T_w$ | 60 °C (333 K) |
| Расход $Q$ | 0,1–2 мкл/мин |
| Состав золя | ТЭОС : EtOH : H₂O : HCl = 1 : 8 : 4 : 0,24 |
| Исходная концентрация Si $c_0$ | ≈ 1,3 моль/л |
| Материал стенки | фотополимер ELEGOO Standard Resin |

Модель сопряжённая: теплоперенос в золе и стенке с условиями сопряжения при $r = R$, пуазейлевское течение ($\mathrm{Re} \approx 10^{-2}$), конвективно-диффузионный перенос с объёмной поликонденсацией $k_v(T)$. Условие Ленгмюра заменено поверхностным стоком первого порядка, потому что рост слоя многослойный и не насыщается:

```math
-D\left.\frac{\partial c}{\partial r}\right|_{r=R}=k_s(T_w)\,c|_{r=R},\qquad
\frac{dm}{dt}=M_{SiO_2}\,k_s(T_w)\,c|_{r=R},\qquad
k_s(T)=k_{s0}\exp\left(-\frac{E}{R_gT}\right)
```

Слой описывается массой на единицу площади $m$ (кг/м²), а не толщиной, что снимает вопрос об усадке геля при сушке.

## Ключевые соотношения

Эффективная константа (последовательные сопротивления реакции и диффузии) и критерий осевой равномерности:

```math
k_{\text{эф}}=\frac{k_s}{1+\dfrac{k_sR}{\mathrm{Sh}\,D}},\qquad
\delta=1-e^{-\mathrm{Da}_{\text{эф}}},\qquad
\mathrm{Da}_{\text{эф}}=\frac{2k_{\text{эф}}L}{R\bar u}+\frac{k_vL}{\bar u}\le-\ln(1-\delta^*)
```

Минимальный расход (при $k_v \to 0$) и допустимая неоднородность температуры стенки:

```math
Q_{\min}=\frac{2\pi R\,L\,k_{\text{эф}}}{-\ln(1-\delta^*)},\qquad
\Delta T^*=\frac{\delta^*R_gT_w^2}{E_{\text{эф}}},\qquad
E_{\text{эф}}=\frac{k_{\text{эф}}}{k_s}E+\left(1-\frac{k_{\text{эф}}}{k_s}\right)E_D
```

Статический режим:

```math
m_{\max}=\frac{c_0M_{SiO_2}R}{2},\qquad
\frac{m(t)}{m_{\max}}=\frac{2k_{\text{эф}}/R}{2k_{\text{эф}}/R+k_v}\left[1-e^{-(2k_{\text{эф}}/R+k_v)\,t}\right],\qquad
\mathrm{Da}_{\text{ст}}=\frac{2k_{\text{эф}}\,t_{gel}}{R}
```

Сужение канала: в статике $R_n = R_0(1-\varepsilon)^n$, $\varepsilon \le 0{,}018$ за цикл; в протоке при $Q = \text{const}$ сужение самовыравнивается, при $\Delta p = \text{const}$ канал зарастает со входа.

Опорный допуск неравномерности для гидрофилизации $\delta^* = 20\,\%$ ($\mathrm{Da}_{\text{эф}} \le 0{,}223$), строгий вариант $\delta^* = 10\,\%$ ($\mathrm{Da}_{\text{эф}} \le 0{,}105$) показывается на рисунках пунктиром.

## Численная проверка

Полная сопряжённая модель решается численно только для подтверждения аналитических критериев и границ их применимости.

- [ ] Предельные случаи: $\mathrm{Sh} = 3{,}66$ и $4{,}36$, решение Левека у входа
- [ ] Сравнение численных и аналитических $\bar c(z)$ и $J(z)$ во всём диапазоне $Q$ и $R$
- [ ] Квазиизотермичность: отклонение $T$ в золе от $T_w$ через несколько секунд
- [ ] Сеточная сходимость, сходимость по шагу времени, материальный баланс (приток = сток + вынос)
- [ ] Чувствительность $Q_{\min}$ и $\Delta T^*$ к литературным $k_{s0}$, $E$, $D$
- [ ] Задача с подвижной границей $R(z,t)$: самовыравнивание при $Q = \text{const}$ и зарастание со входа при $\Delta p = \text{const}$
